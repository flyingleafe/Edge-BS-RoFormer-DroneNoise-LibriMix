# docs/experiments/bets/ — Live PhD-Bet Detail Cards

One markdown file per **active** experimental bet from `GOALS.md`'s "Current
Portfolio". A card expands the GOALS.md headline into the working detail:
hypothesis, MVP definition, kill criterion, time budget, current status, and
running notes/links (runs, checkpoints, configs).

Empty until a bet starts. As of 2026-07-03 the three portfolio bets
(pseudo-RPS, multi-task RPS head, parametric harmonic-comb) are defined in
`GOALS.md` but not yet started — see `GOALS.md` § "Current Portfolio".

Distinct from the parent `docs/experiments/` log, which records **completed /
background** experiments (motivation/results/conclusion). When a bet
concludes, its card stays here and a write-up lands as a top-level file in
`docs/experiments/`.
