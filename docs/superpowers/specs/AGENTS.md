# docs/superpowers/specs/ — Postdoc Design Specifications

Architecture and design documents for the postdoc experiment orchestration platform.

## Why this directory exists

Contains the intended design of postdoc's features, some of which may not yet be fully implemented. Read these to understand the vision, but check source code for current state.

## Caution

Specs describe the target design, not necessarily the current implementation. When in doubt, read `src/postdoc/` source code.
